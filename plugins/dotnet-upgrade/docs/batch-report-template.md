### Status values

| Status | Meaning |
|---|---|
| `Done` | TFM updated, packages bumped, build + test pass, commit created on branch |
| `Partial` | TFM updated and committed but with non-blocking warnings recorded in `upgrade-notes.md` |
| `Reverted` | Build/test failed after 3 cycles; edits reverted; component moved to manual review  |
| `Blocked` | Excluded from the batch at discovery time due to incompatible dependency  |
| `Skipped` | Already on `targetDotnetVersion` or excluded by config |
