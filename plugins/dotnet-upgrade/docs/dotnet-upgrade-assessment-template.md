## Step-by-Step Upgrade Path

1. Resolve scope from `componentPaths` minus `exclusions`.
2. Verify internal package readiness from configured feed.
3. Upgrade/rebuild internal libraries first when required.
4. Update direct packages to target-compatible versions.
5. Replace deprecated packages and APIs.
6. Update Azure Functions to supported isolated worker/runtime settings.
7. Build and fix compile/runtime issues.
8. Run tests (internal libraries first, then consuming solutions).
9. Update CI/CD SDK/runtime/container settings.
