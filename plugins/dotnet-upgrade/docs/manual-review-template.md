# Manual Review List — Template

> ⚠️ **READ-ONLY TEMPLATE — DO NOT EDIT THIS FILE.**
> The agent appends rows to `docs/manual-review-list.md` whenever:
> - a component is classified ` blocked` during discovery , OR
> - a component fails build/test after 3 fix iterations and `revertOnFailure: true` causes its changes to be reverted .
>
> Reverted components are removed from the active batch but do **not** block the remaining components.

### Reason values

| Reason | Meaning |
|---|---|
| `incompatible package` | Required package has no `targetDotnetVersion`-compatible build  |
| `build failure (3 cycles)` | `dotnet build` failed after 3 targeted fix attempts |
| `test failure (3 cycles)` | `dotnet test` failed after 3 targeted fix attempts  |
| `deprecated API` | Code uses an API removed in target TFM; needs human-led refactor |
| `multi-target conflict` | `TargetFrameworks` removal is a judgement call |
| `internal lib not rebuilt` | Internal feed has no target-compatible version of an internal package |
